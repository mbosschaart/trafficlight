Traffic Light API Documentation

Complete API reference for the Traffic Light Control System

← Back to Traffic Light

Base URL

http://localhost:5000

Authentication

No authentication required for this API.

Get Traffic Light Status

GET /api/traffic-light/status

Retrieve the current status of the traffic light.

Response

{
  "color": "red",
  "timestamp": "2024-01-15T10:30:00.123456",
  "success": true
}

Response Fields

Field Type Description
color string Current traffic light color (red, yellow, or green)
timestamp string ISO 8601 timestamp of when the color was last changed
success boolean Indicates if the request was successful

Example Request

curl -X GET http://localhost:5000/api/traffic-light/status

Set Traffic Light Color

POST /api/traffic-light/status

Change the traffic light to a specific color.

Request Body

{
  "color": "red"
}

Request Fields

Field Type Required Description
color string Yes Traffic light color: "red", "yellow", or "green"

Success Response (200)

{
  "color": "red",
  "success": true,
  "message": "Traffic light set to red",
  "timestamp": "2024-01-15T10:30:00.123456"
}

Error Response (400)

{
  "success": false,
  "error": "Invalid color. Must be one of: red, yellow, green"
}

Example Request

curl -X POST http://localhost:5000/api/traffic-light/status \
  -H "Content-Type: application/json" \
  -d '{"color": "green"}'

Get Valid Colors

GET /api/traffic-light/colors

Get a list of all valid traffic light colors.

Response

{
  "colors": ["red", "yellow", "green"],
  "success": true
}

Example Request

curl -X GET http://localhost:5000/api/traffic-light/colors

HTTP Status Codes

Code Description
200 OK - Request successful
400 Bad Request - Invalid input data
500 Internal Server Error - Server-side error

Testing the API

You can test the API using curl, Postman, or any HTTP client. Here are some examples:

Test Sequence

# 1. Check current status
curl -X GET http://localhost:5000/api/traffic-light/status

# 2. Set traffic light to green
curl -X POST http://localhost:5000/api/traffic-light/status \
  -H "Content-Type: application/json" \
  -d '{"color": "green"}'

# 3. Verify the change
curl -X GET http://localhost:5000/api/traffic-light/status

# 4. Try setting an invalid color (should return error)
curl -X POST http://localhost:5000/api/traffic-light/status \
  -H "Content-Type: application/json" \
  -d '{"color": "blue"}'

Interactive Testing

Use the main application interface at http://localhost:5000 to test the API interactively with buttons and real-time updates.
